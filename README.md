# Hytale Shop Telegram Bot 🚀

Автоматизированный Telegram-бот для продажи товаров (аккаунтов/услуг) по игре **Hytale**. Бот поддерживает полный цикл сделки: от выбора товара до проверки оплаты администратором.

## ✨ Особенности

### Для пользователей:
* 🛒 **Интуитивное меню**: удобный процесс покупки через Inline-кнопки.
* 📸 **Загрузка подтверждений**: отправка скриншота оплаты прямо в бота.
* 🔐 **Безопасность**: сбор необходимых данных (Email/Пароль) только после подтверждения намерения оплаты.
* ❌ **Отмена заявки**: возможность отозвать заявку в любой момент до её обработки.

### Для администратора:
* 🛠 **Админ-панель**: получение полных отчетов о новых заявках со скриншотами.
* ⚡ **Быстрые решения**: кнопки «Принять» и «Отклонить» прямо под заявкой.
* 📝 **История данных**: сохранение данных клиента в сообщении даже после вынесения решения.
* 🔔 **Уведомления**: автоматическая рассылка статуса заказа пользователю.

## 🛠 Технологии
Language: [Go (Golang)](https://golang.org/)
Library: [Telebot v3](https://github.com/tucnak/telebot)
Configuration: JSON & Environment variables (.env)

---

 Инструкция по запуску

1. Требования
* Установленный Go 1.20 или выше.
* Токен бота от [@BotFather](https://t.me/BotFather).

2. Клонирование репозитория
```bash
git clone [https://github.com/migo-554/hytale-telegram-bot.git](https://github.com/migo-554/hytale-telegram-bot.git)
cd hytale-telegram-bot

3. Настройка окружения

Создайте файл .env в корневой папке:
Фрагмент кода

BOT_TOKEN=ваш_токен_бота

Настройте файл config.json (пример):
JSON

{
  "admin_id": 123456789,
  "price_text": "5000 руб.",
  "boosty_link": "[https://boosty.to/yourlink](https://boosty.to/yourlink)",
  "messages": {
    "greeting": "Добро пожаловать в магазин Hytale!",
    "info": "Информация о товаре...",
    "instructions": "Инструкция по оплате...",
    "get_email": "Введите ваш Email:",
    "get_password": "Введите ваш пароль:",
    "success": "Заявка отправлена администратору!"
  }
}

4. Установка зависимостей и запуск
Bash

go mod tidy
go run cmd/bot/main.go

⚠️ Важное примечание по безопасности

Никогда не фиксируйте файлы .env и config.json в системе контроля версий Git. Они добавлены в .gitignore для защиты вашего токена и персональных данных.
